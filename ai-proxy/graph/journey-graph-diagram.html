enrich_journey
Computes _daysStale and _isDefaultName flags; extracts audience IDs from the journey payload. Decides whether audience resolution is needed.
resolve_audiences
Agent 1. Calls the AJO Audience API to fetch human-readable audience definitions. Requires ajo_token and audience IDs in state.
skip_audiences
No-op pass-through when journey has no audiences or no API token is available. Merges back into the main flow before scoring.
score_journey
Agent 2. Builds a structured prompt from enriched journey data and calls the Ollama LLM to produce a scored JSON recommendation.
parse_result
Extracts JSON from raw LLM output. On failure increments retryCount. Routes back to score_journey if retries remain (max 2), otherwise terminates.
